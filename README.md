# Clinical Fairness Auditing & Bias Mitigation Framework

This project audits clinical prediction models for unfairness and explores practical ways to reduce it. It uses hospital readmission risk as a case study, built on the **Diabetes 130-US Hospitals dataset**.

## Why This Project Exists

Healthcare algorithms can sometimes perform differently for different groups of patients, even when that was never intended. If left unchecked, these differences may reinforce existing inequalities in care.

This project provides a reproducible way to examine whether a clinical risk model treats patients fairly across demographic groups, particularly **race** and **gender**. It measures disparities, explains what may be driving them, and tests whether simple threshold-based approaches can reduce them.

## What It Does

- **Prevents patient-level data leakage:** Ensures that encounters from the same patient are not split across both the training and test sets.
- **Measures uncertainty:** Uses 1,000 bootstrap samples to calculate 95% confidence intervals around fairness disparities.
- **Explains model decisions:** Uses SHAP to show which features influence predictions, both across the whole model and for individual patients.
- **Tests mitigation strategies:** Compares a single global decision threshold with group-specific thresholds to see how each approach affects fairness and performance.


## Dataset

The analysis uses the [Diabetes 130-US Hospitals dataset](https://archive.ics.uci.edu/dataset/296/diabetes+130-us+hospitals+for+years+1999-2008), which contains hospital encounter records for patients with diabetes from 130 US hospitals between 1999 and 2008.
